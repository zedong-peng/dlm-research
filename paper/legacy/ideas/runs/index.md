## Current Convention

- Keep raw phase JSON, LaTeX, markdown cards, and rendered PDFs inside the run folder.
- Put human-maintained conclusions in [[research/dlm/paper/legacy/ideas/index]] and audit details in [[research/dlm/paper/legacy/ideas/audits/index]].
- Do not cite a generated run artifact as evidence unless the underlying paper or audit page also supports it.
